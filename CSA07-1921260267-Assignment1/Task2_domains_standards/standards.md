# Task 2 – Standards

| Technology | Standard | Body |
|---|---|---|
| Ethernet | IEEE 802.3 | IEEE |
| Wi-Fi | IEEE 802.11 | IEEE |
| IPv4 | RFC 791 | IETF |
| OSI | ISO 7498 | ISO |
| 5G | 3GPP Rel 15+ | 3GPP/ITU |

**Why standards matter:** interoperability, security verification, lifetime support, vendor independence.
